# QA 리포트 출력 형식

> `qa-verification` 스킬의 참조 파일. 본문에서 떼어 둔 이유는 이 내용이 **특정 국면에서만** 필요하기 때문이다 — 스킬이 트리거될 때마다 컨텍스트에 올리지 않는다.

## 출력 형식
`_workspace/05_qa_report_round{N}.md`:

```markdown
# QA 리포트 — Round {N}

## TDD 게이트
- 커버리지: {100% | 미커버 REQ 나열}
- 테스트 실행: {전체 M / 통과 / 실패}

## REQ별 검증
| REQ-ID | 결과 | 근거/비고 |
|--------|------|----------|
| REQ-001 | PASS | test_login_* 통과 + 동작 확인 |
| REQ-002 | FAIL | 경계면 불일치 (아래 버그 #1) |

## 통합 정합성
- API↔프론트: {발견 사항}
- 라우팅: {발견 사항}
- 상태전이: {발견 사항}

## 버그 목록
### 버그 #1 (→ {담당 개발자})
{위 버그 리포트 형식}

## 종합
- 전체 PASS 여부: {예/아니오}
- blocker {n}, major {n}, minor {n}
```
